## 一、 产品愿景与架构演进

在日常办公、研报阅读和职场协作中，专业黑话、形式主义缩写、复杂术语层出不穷。**「人话翻译器」（Human Text Translator）** 基于 Chrome Extension Manifest V3、React 19 与 WXT 架构开发，致力于帮助打工人与知识工作者消除信息不对称。

## 二、 v1.4.0 重大更新功能（New Features）

### 1. 侧边栏提示词排队队列系统（Prompt Queue System）

#### 业务痛点
在 Chrome 侧边栏进行深度连环追问时，AI 的思考和流式打字输出通常需要数秒至十余秒。旧版在 AI 输出期间会强制禁用输入框，用户有了连环新灵感只能憋着等 AI 吐完再输入，严重打断深度思考心流。

#### 核心机制与体验
1. **忙碌态持续输入与入队**：
   - 当 AI 正在思考（Thinking）或流式输出回答（`isStreaming === true`）时，底部输入框依然保持开放；
   - 用户敲击回车或点击右侧【排队发送】按钮，当前提示词（连同附带的截图或划词上下文）会自动进入**先进先出队列（FIFO）**；
   - 输入框瞬时清空重置，支持用户一气呵成连续推入第 2、第 3 个连环问题。
2. **精致队列卡片条（PromptQueueBar）**：
   - 紧密悬浮于输入框正上方，带有**琥珀色脉冲呼吸灯**与 `排队中 (1/N)` 状态 Badge；
   - 实时预览队首问题摘要，并支持展开多条管理抽屉；
   - **交互按键**：
     - `[↑]` **优先发送**：直接打断当前流式输出，将排队项抢先送入模型；
     - `[×]` **移除/取消**：一键剔除不想问的排队项，支持全量清空；
     - **全平台打断快捷键**：按下 `⌘ + Enter`（Mac）或 `Ctrl + Enter`（Windows），无需触碰鼠标即可抢占打断当前回答并立即发送排队问题。
3. **自动串联调度（Auto-dispatch）**：
   - 当前一个问题全部回答完毕时，调度器自动从队列中取出首项（`queue.shift()`），自动触发下一次提问；
   - 实现“用户一次性抛出 3 个问题，AI 依次不间断全自动连续作答”的极致爽感。

### 2. 多维视角三棱镜表达引擎（The Translation Prism）

职场沟通不仅需要**“向下兼容解码”**，更需要**“向上管理编码”与“破译弦外之音”**。单次翻译输出已全面升级为三棱镜多维表达体系：

| 表达维度 | 核心定位与场景 | 示范示例 |
| :--- | :--- | :--- |
| **🍼 直白人话版** | **老妪能解，生活化打比方，撕碎一切形式主义伪装** | **原文**：“我们需要联动多方资源，强化协同机制，赋能业务增长。”<br>**人话**：“大家别各自为战了，一起凑个会分工干活，帮业务多拉点客户。” |
| **👔 向上汇报版** | **高情商打工人神器：大白话秒变周报述职范本** | **原文**：“我们修了几个按钮 Bug，现在网页不卡了。”<br>**汇报**：“完成端到端交互韧性重构，深度优化关键路径渲染损耗，推动用户链路流畅度显著提升。” |
| **🔪 犀利真相版** | **幽默破译潜台词，看穿职场内耗与防忽悠** | **原文**：“这个方案我们后续保持观察，待时机成熟后再推进。”<br>**真相**：“现在不想做，以后大概率也不做，先把你糊弄过去。” |

#### 交互落地与一键复制周报
* **自由开关与纯净原生态（默认关闭）**：在设置页【划词与交互】新增「多维视角三棱镜模式」独立开关，**默认处于关闭状态**。关闭时 100% 走纯净原生态链路（仅带上用户自己配置的系统提示词与问题，绝不额外内嵌三段式 prompt）；用户按需开启后，才会让模型生成多维视角；
* **三 Tab 平滑切换**：开启状态下，划词原地浮窗（Popup）、侧边栏（Sidepanel）会话以及扩展弹窗中均配备三棱镜 Tab 药丸切换栏；
* **一键复制汇报版**：右上角配备高亮【👔 复制周报版】按钮，一键提取高情商汇报文字至剪贴板，直粘飞书、周报或汇报 PPT。

### 3. 极速低阻交互：Alt / Option + 划选即译

* **操作痛点**：传统划词必须经历 `选中文本 ➔ 鼠标移向浮动条 ➔ 点击翻译图标` 三步操作；
* **极客解法**：在任何网页中，只要按住键盘 `Alt`（Mac 上的 `Option` 键）选中文本松手，**直接在鼠标落点原位瞬时唤起翻译浮窗**，跳过一切中间操作条，单步闭环。

---

### 4. 全屏独立标签页设置中心（Full-Tab Options Workspace）

* **全屏大视野**：设置页全面升级为全屏浏览器独立标签页，不再受制于扩展图标下狭小的弹窗；
* **四维分类导航**：
  1. 🔑 **API 与模型**：支持主流大模型（DeepSeek、火山引擎、月之暗面、通义千问、OpenRouter 等）自定义配置与连通性测试；
  2. ⚙️ **划词与交互**：快捷条触发机制、上下文感知模式、思维链（Thinking Chain）开关配置；
  3. 🎨 **外观显示**：跟随系统/亮色/暗色主题无缝切换，独创**全扩展 80%~140% 阶梯字号滑块与实时预览对照卡片**；
  4. 🛡️ **备份与诊断**：一键生成全量结构化 JSON 备份（历史记录、生词本、会话设置一键迁移恢复）与运行期脱敏诊断日志追踪。
* **测试成功自动持久化**：点击“测试连接”成功后，后台即刻自动落盘配置，彻底杜绝“测试成功但忘记点保存”导致的密钥丢失问题。

## 三、 整体核心功能矩阵全景

人话翻译器当前拥有 4 大功能矩阵，覆盖网页浏览与知识消化的全部场景：

### 1. 页面级智能提取与深度漫游
* **Shadow DOM 穿透提取**：针对现代 Web Components 和隔离组件，通过原位 Composed Tree 遍历与 `<slot>` 节点投影提取，彻底解决封闭组件内文字无法读取的难题；
* **长网页虚拟列表启发式通读（Deep Web Reading）**：针对飞书文档、语雀、知乎、Twitter 等动态懒加载和虚拟滚动长页面，具备密度自适应检测、增量滑动收割与自动瞬间复原视口（Zero Reflow）。

### 2. 多形态人机交互
* **划词原位浮窗**：自适应避障、防遮挡、支持自由拖拽与三棱镜结果切换；
* **全功能侧边栏（Sidepanel）**：支持多轮长会话追问、历史会话切换、长文通读分段缓存与划词跨窗口漫游；
* **右键菜单与全局快捷键**：选中文字一键呼出，支持自定义快捷键唤起。

### 3. 数据资产与本地安全
* **黑话生词本（Jargon Vault）**：记录遭遇过的行业黑话，内置 Fuse.js 模糊检索与划词命中复用缓存；
* **敏感安全隔离**：用户配置的 API Key 严格保存在本地设备（`chrome.storage.local`），**绝不同步至云端服务器**，从根源消除安全顾虑。
