# 26.10.18

## What's changed

- 新增自动交互讲解：AI 可按问题需要选择层级树、步骤、概念标签、比较表或图表，在同一条回答中展示文字与交互内容。
- 新增 ECharts 折线图、柱状图和饼图；流式生成时先显示已完成且校验通过的部分，结束后保存完整卡片及可恢复操作状态。
- 修复标签页草稿初始化竞态：会话与草稿恢复完成前暂停输入和发送，避免新输入被迟到的恢复值覆盖。
- 补充草稿延迟恢复、存储写入核对、重复切换和关闭重开的回归测试。
- 版本采用北京时间 YY.M.D；同日后续发布追加 .1、.2，例如 26.10.18.1。

## 怎么用

在侧栏正常提问，AI 可自行生成适合的交互讲解；设置中可关闭「自动交互讲解」。图表、卡片和文字均在原会话内查看，继续追问仍沿用已保存上下文。

侧栏跟随标签页。首次打开时等待输入框恢复可用后即可输入；各标签页保持自己的草稿。关闭侧栏再打开也会恢复已保存草稿。

最低 Chrome 142。沿用现有权限、模型配置、截图和请求链路。

## 发布准备

package.json、wxt.config.ts 与打包 manifest 均使用 26.10.18。既有发布工作流由版本标签或手动运行触发，并校验标签、包名版本与 manifest 一致；目前没有自动生成日期版本号的脚本。

本轮仅合入主分支并完成验证与打包准备，尚未创建日期版本标签或触发商店上传。提交审核与正式公开将在发布时分别报告。
