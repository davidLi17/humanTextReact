# v1.10.0

## 本次内容

- AI 会按问题需要自行决定是否调用交互讲解工具；调用后侧栏直接展示结构化内容，无需手动切换模式。
- 保留目录树和步骤卡片，新增 ECharts 折线图、柱状图与饼图；生成期间逐步显示预览，完成后保存操作状态。
- 流式生成支持中止、重试与不完整内容处理；保留已有文字回答，取消或失败时清除未完成预览。
- 有效交互卡片不会因 fallback 摘要缺失、为空或过长而被丢弃；工具参数超限时停止继续拼接并显示明确提示。
- 延续 1.9.2 的侧栏按标签页隔离：每个页面各自恢复会话、草稿、图片和选区上下文。
