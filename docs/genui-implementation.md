# 人话翻译器 GenUI 第一版集成说明

## 交付状态

1.8.0 将旧 GenUI 预览补丁整合到 main 提交 `e5e70618b8b0eb3ac270b230965a977a6f6e50ea`（1.7.2），保留设置自动保存修复。发布与商店审核状态以对应 GitHub Actions 运行结果为准，提交审核不等于公开上线。

本次测试使用仓库固定的 Bun 1.4.0；`.bun-version` 未修改。新增依赖固定为 `@json-render/core@0.21.0`、`@json-render/react@0.21.0`、`zod@4.3.6`，更新 Bun lockfile。按实际安装包的类型和源码验证 API；使用项目适配层，不 fork 框架。

## 已实现

- Side Panel 已完成回答下方新增“交互讲解”。点击新建用户请求与助手消息，原回答保留。明确重试同样保留来源，不自动无限修复。
- Card、Text、TreeInspector、ConceptTabs、CompareTable、StepViewer 六类预打包组件。支持树节点关系检查、概念标签切换、表格排序/筛选、步骤演示。点击控件不请求模型。
- 复用当前 Background BYOK Chat Completions/SSE 通道。GenUI 明确关闭 Prism 和生词本复用，不改变未知网关格式，不新增结构化输出 API 要求。
- 模型 JSON 只进入私有缓冲；正常结束、完整解析并通过白名单校验后，才一次性交付可读摘要与附件。取消、截断、中断、超时、非法输出均不给出卡片。
- 按 requestId、sessionId、assistantMessageId 和冻结来源元数据认领结果。普通文字仍流式显示；普通追问仅使用文本摘要。
- 卡片独立状态域、文字版本、复制摘要、填入追问草稿、来源提示、渲染错误边界。
- 会话恢复、备份导入和 JSON 导出重新校验附件；Markdown/纯文本导出保留可读正文。所有写入走已有串行存储队列。
- 本地“交互讲解”开关，关闭后历史卡片仍显示文字；开关加载与连续写入顺序有保护。

## 安全和容量边界

- `explanation-v1` 严格字段和组件白名单；未知属性、动作、watcher、绑定、表达式、动态路径、任意网络能力均不能进入 Renderer。
- 文本使用 React 文本节点；模型无法注入 HTML、脚本或可执行 JSX。宿主自加元素身份仅在严格校验后产生。
- 原始 JSON 上限 65,536 UTF-8 字节。元素最多 100 个、引用深度最多 8；树数据最多 100 节点且必须单根无环；表格最多 200 行。严格检查重复 ID、危险/原型键、未引用节点、未知引用、属性长度和状态值。
- 生成附件在计入本地来源元数据后最多 61,440 字节，为状态预留空间；只有最终附件校验通过才发布成功和保存摘要历史。
- 每张卡片持久化最近约 4KiB 视图状态，另按实际附件剩余容量收紧。数字 ID 使用独立访问顺序，最近操作优先保留。容量不足时保留内存交互，提示较早选择不会保存；重开后较早控件可能回到初始位置。表格排序/筛选仅保留在本次打开期间。
- 全会话附件预算 1MiB；统一持久化边界先清理旧视图状态，再移除较早附件，保留文字。后续网页阅读进度快照不能绕过此预算。
- Manifest 仅升级版本号，权限和 CSP 均未变更：`script-src 'self'; object-src 'self'`。所有执行代码随扩展打包。

## 本地安装与验证

1. 将 `human-language-translator-1.8.0-chrome.zip` 解压到新的固定目录。
2. 打开 Chrome 扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选择含 `manifest.json` 的目录。
3. 如要替换已加载开发版，请先保留旧目录和配置备份，并确认 Chrome 实际加载路径；本次未替换你的电脑上的任何目录。
4. 在扩展设置中使用你自己的模型配置。打开侧边栏，得到一个完成的回答后点击“交互讲解”。若模型输出不符合协议，原回答仍可读，可明确重试。
5. 点击树/标签/步骤控件，确认没有新增模型调用；切换文字版本，重开侧边栏检查最近状态。关闭开关应保留摘要。

源码复现：`bun install --frozen-lockfile`，随后 `bun run compile`、`bun run test`、`bun run test:shared`、`bun run test:coverage`、`bun run test:e2e`、`bun run build`。需要可启动 Chromium 的环境才能完成 E2E；若使用系统 Chromium，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`。

本次直接复用旧补丁；设置自动保存相关代码保持在 1.7.2 基线上。新版本说明见 `release-1.8.0.md`。
