# v1.8.0

## What's changed

- 已完成回答下方新增“交互讲解”：主动点击后新建一轮，原回答保留。复用现有模型设置、网页上下文与会话存储。
- 支持树节点查看、概念标签、比较表格和步骤演示，以及卡片、文本两种基础组件。控件交互在本地执行。
- 结构化输出完整缓冲并校验；错误保留文字回退。增加请求身份隔离、历史/导入校验、附件容量限制和本地开关。
- “结合当前段落解释”改为简短摘要和悬停提示，分为发送数据与具体示例；支持键盘聚焦、Escape 关闭和暗色主题。
- 保留 1.7.2 设置自动保存修复，扩展权限和 CSP 不变。

## 使用方式

打开侧边栏，待回答完成后点击下方“交互讲解”。树节点、标签、表格和步骤可直接操作；卡片可切换文字版本。若模型输出未通过校验，继续阅读原回答或主动重试。

## 验证与限制

- Bun 1.4.0；类型检查、495 项基础测试、59 项组件测试、495 项共享环境随机顺序测试通过。
- Chrome 生产构建与 ZIP 打包通过；包名 `human-language-translator-1.8.0-chrome.zip`。
- 本地 E2E 因托管 Chromium 禁止扩展及浏览器下载 403 受阻；完整 11 项浏览器测试由现有 CI / 发布流水线验证。
- 测试使用 mock 模型，未进行真实供应商调用。B+ 树算法模拟器、流式卡片、原位多轮修订延后。
- 上传商店后仍须审核；提交审核与公开上线分别报告。
