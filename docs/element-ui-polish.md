# 网页标记 UI 打磨

基于 c398c51。本轮只调整呈现与界面布局，不更改截取、快照文本、模型请求、权限或版本。

What's changed：
- 网页输入框统一圆角、边框、间距与焦点样式，增加标题，主按钮突出；父级操作和提交操作分行。窗口边缘自动调整位置。
- 选框改为低透明度靛蓝色，编号圆点统一样式；摘要与问题使用自定义 hover/focus 提示，优先在目标旁显示。
- 侧栏附件卡片区分编号、标题、状态与问题；长说明收进 hover/focus 提示，不使用 modal。
- 快照预览先显示图片，再显示可滚动的完整原文；实际发送文本与截图不变。统一发送按钮保持可见的独立层级。
- 侧栏沿用项目深浅主题变量，网页浮层跟随系统深浅模式；兼容窄侧栏与长文本。

验证：Bun 1.4.0，类型检查、Chrome 构建、562 项测试通过；普通浏览器模块测试 1 项通过，包含点选、输入、标记、双向 hover、截图遮盖/像素、payload、恢复和清理；增加 320px 深色侧栏长问题无横向溢出及键盘 tooltip 检查。实际查看输入、标记、浅色预览、深色窄侧栏截图，并修正提示遮挡与按钮换行。

浏览器截图来自真实 Chromium 页面中运行的生产模块；扩展消息和截图 API 入口使用 mock。此前管理策略禁止加载扩展的限制仍存在，本轮未绕过策略，不能代替真实安装扩展验收。未调用真实模型、未推送、未发布、未更改商店权限。Linux 环境无法更新用户 Mac 的固定加载目录。
