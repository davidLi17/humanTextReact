# 交互讲解最终渲染修复

工具流已经产生可用预览，但最终校验失败且没有普通正文或 fallbackText 时，旧流程会删除预览并显示“模型未返回可显示内容，请检查模型或接口兼容性”。实际问题发生在交互内容的最终校验和回退阶段，不能据此判断模型不支持工具调用。

- 省略 children 与显式空数组统一处理。叶子组件不再因为这一差异在预览成功后被最终校验拒绝；非空子节点和图表数据仍执行原有校验。
- 最终失败保留明确的校验原因，例如“图表分类数量与数值数量不一致”。诊断日志记录原因，不记录工具原始参数或字段值。
- 有可用的预览文字时保留文字并提示校验失败。不会把预览中裁剪过的图表或数值保存成完整成功结果；没有文字时明确报告渲染原因。
