# 交互讲解最终渲染修复

工具流已经产生可用预览，但最终校验失败且没有普通正文或 fallbackText 时，旧流程会删除预览并显示“模型未返回可显示内容，请检查模型或接口兼容性”。实际问题发生在交互内容的最终校验和回退阶段，不能据此判断模型不支持工具调用。

- 省略/null children 与空数组统一处理；Card 可省略 props，空的可选标题直接省略，步骤缺少说明默认为空文字。生成结果只提取支持的字段，非必要样式和多余字段不再阻断整张卡片；展示元素的非标准 ID 会重映射。
- 最终按组件校验并隔离失败。无效组件、重复/缺失/成环引用只影响局部；独立合法组件保留并整理层级，提示局部省略或调整。存储和渲染仍只接收经过严格数据校验的白名单组件。
- 最终失败保留明确的校验原因，例如“图表分类数量与数值数量不一致”。诊断日志记录原因，不记录工具原始参数或字段值。
- 局部图表无效时，保留其它合法卡片；无法保留卡片时，再保留可用文字。不会把预览中裁剪过的图表或数值保存成完整成功结果，不补造数据；没有文字时明确报告渲染原因。
