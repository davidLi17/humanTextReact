# 交互讲解最终渲染修复

源码确认：工具流用 partial-json 生成预览，但结束时 finishAuto 重新解析完整 JSON。最终失败时后台没有交付 genUi，侧栏完成处理又清掉 genUiPreview，因此已显示的卡片消失。

本次改动：

- 预览和最终生成共用组件恢复逻辑。生成内容的额外字段、版本格式和 fallbackText 缺失或长度不再阻断可用卡片；持久化元数据与请求归属仍严格验证。
- 展示 key 可重映射，节点/步骤/表格 ID 支持中文与空格；保留原型污染保护。坏步骤、坏树分支、缺失或重复引用局部跳过。表格缺失单元格为空，图表只保留模型已提供的有效分类/数值对，不补造数值。
- 未闭合 JSON 尝试恢复有效部分，不使用截断的 fallbackText。尾部无法恢复时，最终交付本次请求最后可用的预览，避免撤卡或把校验诊断作为回答。工具以 stop 或 length 结束且已有可用预览时同样保留。
- 请求取消、过期、权限检查、数据白名单、安全隔离与容量限制保持。未新增模型重写或重试路径。

验证：新增流式预览后损坏尾部、正常完成、重新生成隔离、手动重新讲解、局部损坏、图表数据不齐、前端预览转正式卡片后持久化等回归。既有安全边界测试保留。使用 mock 模型接口，未调用真实模型。
