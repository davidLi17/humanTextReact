# 26.10.19.2

## What's changed

- 修复网页元素文字中大片无用空白：普通正文会清理重复空格、行首尾空白和嵌套容器叠加的空行，保留段落分行。
- 表格保留行、列和空单元格；pre/code 保留有意义的缩进、连续空格和空行。预览、保存与发送使用同一份整理后的快照。
- 元素悬停采用淡蓝半透明底色和细轮廓，点击锁定时颜色稍深，并显示「已选 · 表格／代码／标题／区域」等简洁标签。
- 改善滚动时的目标命中与高亮跟随，编辑框内的文字选区在位置刷新后保留。高亮无闪烁和额外阴影，不增加主题或设置项。

## 怎么用

开启「选择网页元素」，悬停并点击需要提问的区域。填写问题后保存标记，或直接「提问」；侧栏展开实际发送快照，可核对整理后的文本、原有表格结构和代码格式。滚动页面时，高亮框和锁定标签会跟随目标。

## 验证

- 功能验收分支通过类型检查、541 项关键测试、541 项共享顺序测试、63 项 React 组件测试和 Chrome 构建/打包。
- 实际打包构建的 17 项扩展 E2E 通过，覆盖正文整理、柔和高亮、锁定标签、滚动命中和文字选区、双向 hover、截图隐私遮盖、预览/发送一致、追问恢复及清理；模型端点与扩展传输均使用 mock。
- 发布准备同步核对 package.json、扩展 manifest 和 ZIP 版本；最终 main CI 与发布流水线继续验证实际构建。

## 发布状态

本版本已获用户验收并准备合入 main，版本号使用 26.10.19.2，不重复使用已公开的 26.10.19.1。由用户在 Release Chrome Web Store 页面选择 main，手动 Run workflow。

流水线上传成功、提交审核和正式公开上线分别以商店实际返回状态为准；主分支 CI 成功不代表已提交审核或上线。
