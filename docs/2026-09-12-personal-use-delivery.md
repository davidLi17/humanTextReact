# 个人日常使用迭代交付记录

日期：2026-09-12。原始提案见 [个人使用迭代提案](2026-09-12-personal-use-iteration-proposal.md)。

目标是读资料时少重复操作：准确带入网页内容、找回以前的回答、留下能继续使用的解释。已按提案顺序完成三项功能，每项独立提交与验证。

## 已实现

| 功能 | 使用方式 | 代码提交 |
| --- | --- | --- |
| 网页上下文可控 | 加入网页后，在网页卡查看实际保存范围、预览原文、选择参与下次提问的段落；关闭重开会恢复选择 | `386340b` |
| 会话内容搜索 | 打开历史抽屉，搜索标题、提问或回答；点击结果定位并高亮原消息，原会话草稿保留 | `ef90cfc` |
| 带语境的收藏 | 浮窗或侧栏点收藏，编辑术语、释义、原句和来源；生词本可查看原文，点“继续问”生成新会话草稿 | `053498b` |

网页加入本身不请求模型。请求文字超出保守预算时，会提示缩小资料范围，并保留输入、队列和已有回答。网页快照按页和全部会话限制容量；页面实际采集范围、保存范围、下次提问选入范围分别显示。

搜索只使用本地会话数据。消息定位会暂停自动跟随到底部，用户仍可使用原有回到底部操作。

收藏优先预填三视角里的直白解释，用户可改成自己的短释义。选区的原句与来源独立保存；纯提问保留原问题。已有存储格式、本地精确复用、搜索和导入导出继续使用。保存失败后编辑内容保留，继续问先展示完整草稿，用户主动发送。
