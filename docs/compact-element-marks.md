# 网页标记轻量 UI 与 Enter 提问预览

基于 tab 侧栏预览 29721c6，继续 feat/tab-bound-sidepanel；不修改版本、不合并 main、不发布。

## What's changed

- 网页平时只显示小编号，优先放元素左/右外侧；边缘放上/下方并限制在视口内。hover 才显示细框、摘要和问题，点击编号展开就地编辑。
- 编辑器主按钮「提问」和 Enter 使用同一提交函数：打开所属标签页侧栏、保存/生成快照，再通过既有侧栏发送链路提交全部待发送标记。Shift+Enter 换行；中文 IME composition 与 keyCode 229 不提交；处理中禁用输入和按钮，同步重复 Enter 只提交一次。
- 次操作「保存并继续选择」只保存标记、不调用模型、不打开侧栏；已有标记可保存问题、取消修改、删除。已有问题编辑复用冻结快照，目标失效则拒绝发送。
- 新增网页右键「标记网页元素并提问」入口，在网页开始选择，无需先展开侧栏。
- 侧栏默认只占一行「已选 N 处」，截图、全文、编辑和批量发送按需展开；列表展开也限制高度，为回答留空间。网页端点击提问后不强制展开标记列表。
- 保留 tab 归属、截图遮盖/裁剪、历史追问、请求身份、取消与队列链路；模型仍由已有侧栏执行，没有新模型服务。
