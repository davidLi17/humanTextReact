# 「人话翻译器」下一代产品功能演进提案
> **版本**：v2.0 规划草案  
> **日期**：2026-09-09  
> **作者**：AI 产品专家 & 浏览器生产力工具设计组  
> **核心定位**：从“单向释义扩展”跃迁为“职场认知加速与双向表达智能中枢”

---

## 一、 产品现状与演进愿景

### 1.1 现状与技术基石
当前人话翻译器（Human Text Translator）已沉淀了业内第一梯队的扩展底层能力：
* **页面交互层**：具备抗遮挡、穿透 Shadow DOM、自适应视口避障的原生划词快捷条（`SelectionActionBar`）与浮窗（`PopupManager`）。
* **工作台层**：具备长文渐进式深读、分段缓存、引用追问的独立侧边栏（`Sidepanel`）。
* **数据沉淀层**：具备统一规范模型、支持 Fuse.js 模糊检索、导入导出的黑话生词本（`JargonVault` / `JargonStorage`），并已实现划词时优先复用本地生词条的秒级命中机制（`jargonReuse`）。

### 1.2 核心痛点与跃迁方向
* **痛点 1（数据冷冻）**：生词本只进不出，用户收藏了 100 个词条，在阅读 Wiki/文档时依然会忘记，“生词本”沦为冷数据归档处。
* **痛点 2（冷启动门槛）**：新用户安装后生词本空空如也，缺少开箱即用的行业黑话词典，无法立刻体验“被黑话赋能”的爽快感。
* **痛点 3（单向解码局限）**：过去只解决“看不懂”，但职场中更普遍的痛点是“不会写”——如何向上汇报？如何看懂字面下的真实潜台词？
* **痛点 4（交互仍有阻力）**：从划选到点击操作条仍需 2~3 步，缺乏极客级的瞬时盲操体验。

**演进愿景**：打造“**学过就主动提醒、装上就拥有行话大脑、不仅能破译还能替我写周报**”的职场必备生产力神器。

## 二、 三大核心功能矩阵深度规划

### 1. 生词本（Jargon Vault）的场景化活化

#### 1.1 网页内“微光反向划线”与即时悬浮卡（Ambient In-Page Highlighting & Mini Peek）
* **功能描述**：
  * 当用户浏览任何网页（如飞书文档、语雀、GitHub、新闻、研报）时，Content Script 自动将用户生词本内已收录的黑话词汇进行非侵入式轻量微光标记（优雅的淡紫色点状虚线或微晶高亮）。
  * 技术上采用现代浏览器的 **CSS Custom Highlight API** 结合轻量 `TreeWalker`，不破坏宿主网页的原生 DOM 结构、零样式污染、无重新排版（Zero Reflow）。
* **Mini Peek 悬浮微卡**：
  * 鼠标悬停在高亮词上 250ms，即时弹出精致毛玻璃微卡片：
    * **核心大白话**：1 句话生活化妙喻（Analogy）；
    * **生词卡信息**：所属分类、记忆次数、记录时间；
    * **即刻操作**：`[已彻底掌握/消灭]`（移出高亮流）、`[追问]`（携带当前句子一键转入侧边栏展开深度聊）。
* **爽感价值**：原本陌生的专业网页变成了“我掌握的知识在主动向我打招呼”，形成极强的心流与认知复利。

#### 1.2 艾宾浩斯遗忘曲线闪卡记忆系统（Jargon Flashcards / SRS System）
* **数据模型升级**：
  * 在 `JargonItem` 中拓展间隔重复（Spaced Repetition System, SRS）字段：
    * `masteryLevel`: 0~5 阶（生疏、初学、熟悉、掌握、精通）；
    * `nextReviewTime`: 下次复习时间戳；
    * `reviewHistory`: 复习频次与遗忘次数。
* **Sidepanel / Popup 沉浸式刷卡**：
  * 侧边栏常驻【今日待复习】轻量入口与徽标提示（如 `待复习 5`）。
  * **卡片正面**：展示术语名，附带当初保存该词时的**真实网页上下文句子**（Contextual Recall），让记忆依托真实场景；
  * **翻面反馈**：一键翻转，展示人话释义与比喻；
  * **三键反馈**：`[模糊/忘记]`、`[想起来了]`、`[完全掌握]`，自动按艾宾浩斯曲线自适应调度下一次复习时间。

### 2. 智能对比与多重表达（多维视角三棱镜：三合一生成）

#### 2.1 三棱镜多维表达引擎（The Translation Prism）
不仅做单向解码，还将输入转化为 3 种极具张力的职场表达维度：

| 表达维度 | 核心定位 | 典型场景示例 |
| :--- | :--- | :--- |
| **🍼 直白人话版** | **老妪能解，打比方，撕碎伪装** | **原文**：“我们需要联动多方资源，强化协同机制，赋能业务增长。”<br>**输出**：“大家别各自为战了，一起凑个会分工干活，帮业务多拉点客户。” |
| **👔 向上汇报版** | **高情商打工人神器：大白话秒变周报述职范本** | **原文**：“我们改了两个按钮的 Bug，现在页面不卡了。”<br>**输出**：“完成端到端交互韧性重构，深度优化关键路径渲染损耗，推动用户链路流畅度显著提升。” |
| **🔪 犀利真相版** | **破译潜台词，看穿职场内耗，减负防坑** | **原文**：“这个方案我们后续保持观察，待时机成熟后再推进。”<br>**输出**：“现在不想做，以后大概率也不做，先把你糊弄过去。” |

#### 2.2 交互落地
* **三 Tab 选项卡 / 紧凑折叠卡**：在原地浮窗与侧边栏中以平铺 Tab 或折叠形态呈现，单次 LLM 提示词流式结构化产出；
* **一键智能复制**：右上角配备“一键复制汇报版”，一秒粘入飞书/企业微信/周报系统，工具打开频次翻倍。

### 3. 极速低阻交互微创新

#### 3.1 按键修饰划词（Alt/Option + 划选即译）
* 痛点：常规划词需要经历 `划选 -> 鼠标移向操作条 -> 点击翻译`，遇到频繁查词时手指负担重。
* 解决方案：按住 `Alt`（Mac 上的 `Option`）划词松手时，**直接在鼠标落点原位唤起翻译浮窗**，单步闭环，达到桌面客户端级极致顺滑感。

#### 3.2 双击极速取词（Double-click Quick Word）
* 针对单个缩写（如“ARR”、“OKR”、“EBITDA”）或双击选中的单个技术词汇，光标右上角轻量呈现微型闪电图标，点击或按空格键即弹词条卡片。

## 三、 代码工程改造路径（Roadmap & Architecture）

对应现有代码目录的落地点设计：

```
entrypoints/
├── content/
│   ├── inPageJargonHighlighter.ts   <-- [新增] 基于 CSS Custom Highlight API 的页面反向划线与 Mini Peek 浮层
│   └── selectionActionBar.ts       <-- [改造] 增加 Alt+划词直接唤起、三棱镜切换按钮
├── shared/
│   ├── jargonTypes.ts              <-- [拓展] 增加 reviewStage, intervalDays 等 SRS 字段
│   ├── srsScheduler.ts             <-- [新增] 艾宾浩斯遗忘曲线算法与到期计算器
│   └── prompts/
│       └── prismTranslationPrompt.ts <-- [新增] 人话/汇报/真相 三合一并行生成系统提示词
├── sidepanel/
│   └── components/
│       ├── JargonFlashcardMode.tsx  <-- [新增] 生词闪卡背词面板（卡片翻转、正反面评星）
│       └── PrismResultTabs.tsx     <-- [新增] 三棱镜多维结果切换器（白话/汇报/真相）
```
