# v1.9.0

## What's changed

- 新增网页元素标记与多模态问答：悬停高亮、点击锁定、就地提问，多标记统一发送。
- 支持父级扩大/返回、问题修改、删除、Esc 取消及网页与侧栏双向高亮。
- 真实局部截图、可见文本、表格与代码组成有界快照；预览与实际发送一致，随消息保存用于追问。
- 表单与可识别嵌入内容遮盖，目标失效提示重选；沿用 activeTab，不新增扩展权限。
- 打磨输入框、编号、提示及侧栏卡片，支持深浅色、窄侧栏和键盘焦点。

## 使用方式

侧栏「选择网页元素」→ 点击网页目标 → 填写问题 →「加入待发送」→ 检查快照 →「发送给AI」。添加快照不会调用模型。需要支持图片输入的模型；首次截图前在当前页点击扩展图标或使用现有右键菜单授予临时访问。

## 验证与发布

本地类型检查、562 项测试、Chrome 构建及普通浏览器模块测试验证；真实安装扩展 E2E 由现有 CI / 发布流水线执行。本地管理策略限制仍存在，测试使用 mock 模型。商店上传、提交审核和公开上线分别报告。
