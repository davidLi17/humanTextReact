# 网页元素文字与柔和高亮

## What's changed

- 普通正文在采集时整理重复空格、DOM 排版缩进、行首尾空白和重复结构换行，避免嵌套卡片生成大片空白；段落仍分行。
- 表格继续用换行分隔行、制表符分隔列，空单元格保留；pre/code 内的缩进、连续空格和空行保持原样。
- 预览、存档和发送使用同一份整理后的快照，不在发送时另外修改文本。
- 悬停使用淡蓝半透明底色和 1px 细轮廓；点击锁定颜色稍深，旁边显示「已选 · 表格／代码／标题／区域」等简洁标签，无闪烁与额外高亮阴影。
- 滚动和窗口变化在动画帧中更新位置，不反复提取所有标记文本；静止指针下的目标在滚动后重新命中。编辑框中的文字选区在刷新定位后保留。

## 怎么验收

进入网页元素选择，悬停并点击标题、表格或代码；滚动页面和缩放窗口，核对框与标签位置。保存标记后在侧栏展开实际快照，检查正文空白、表格列和代码缩进，再发送或追问。

功能已通过用户验收，随 26.10.19.2 准备发布。未新增设置或调整消息推送方式；版本说明及发布状态见 release-26.10.19.2.md。
