# 26.10.19.1

## What's changed

- 修复交互讲解在生成过程中正常显示、生成完成后整张卡片消失的问题。
- 放宽可选字段与非必要格式要求：省略的子节点、空的可选标题、步骤说明和多余样式字段不会再阻断其它可用内容。
- 局部组件出错时保留其余合法组件。无效图表只省略该图表并显示原因，不补造数值；缺失、重复或成环的组件引用会被整理，独立可用内容继续显示。
- 没有可用卡片时保留可读文字，说明具体渲染原因，避免误报为模型或接口不兼容。
- 卡片、局部省略提示与文字摘要可随会话保存，刷新恢复后继续追问。

## 怎么用

照常在侧栏提问并生成交互讲解。流式生成结束后，已生成的合法卡片会继续显示；若某一部分无法显示，可查看卡片附近的原因提示，再继续追问或重新生成。

## 验证

- 修复代码已通过类型检查、537 项关键测试、537 项共享顺序测试和 63 项 React 组件测试。
- Chrome 扩展 17 项完整 E2E 覆盖流式预览到完成、合法卡片保留、局部错误隔离、刷新恢复与追问，以及网页元素截图和原有主流程。模型端点均使用 mock。
- 本版本同步更新 package.json 与扩展 manifest 版本，构建后核对 ZIP 内 manifest；发布流水线会对实际上传构建再次执行检查与 E2E。

## 发布状态

此版本包含 main 上已合入的 GenUI 修复，使用新版本号 26.10.19.1，不重复上传 26.10.19。提交审核和正式上线分别以 Chrome Web Store 实际返回状态为准；流水线提交审核成功不等于已公开上线。
