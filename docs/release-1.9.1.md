# v1.9.1

## What's changed

- 侧栏跟随标签页：未开启的页面隐藏，返回已开启页面恢复；各标签页独立保存活动会话、草稿、图片与选区上下文，历史仍可共享检索。
- 关闭侧栏后切回不主动重开；明确打开时恢复草稿。保持多窗口与后台 Worker 重启后的标签页归属。
- 网页标记默认只留元素外侧小编号，hover 显示细框与摘要，点击编号就地编辑、保存、取消或删除。
- 侧栏标记清单默认折叠为一行「已选 N 处」，快照、长文与编辑按需展开，为 AI 回答留出空间。
- 网页问题框 Enter 与「提问」按钮执行同一实际发送操作；Shift+Enter 换行，中文输入法确认不误发，处理中防重复提交。
- 新增网页右键「标记网页元素并提问」，保存标记无需先打开侧栏。

## 使用方式

1. 网页右键选择「标记网页元素并提问」，或使用侧栏「选择网页元素」。
2. 点击目标，填写问题。「保存并继续选择」只加入待发送清单，不调用模型、不强制打开侧栏。
3. 按 Enter 或点击「提问」，打开该标签页侧栏，将全部待发送标记交给 AI；Shift+Enter 换行。
4. 点击网页编号修改问题；侧栏展开「已选 N 处」可核对实际发送快照。局部截图、文本/表格/代码随消息保存，追问继续使用冻结上下文。

截图需支持图片输入的模型；沿用 activeTab 临时访问，不新增权限或凭据。网页右键入口或点击当前页扩展图标可授予截图所需临时访问。

## 最低版本与验证边界

最低 Chrome 142：侧栏原生关闭事件 sidePanel.onClosed 从该版本提供，用于记录浏览器关闭动作。参见 https://developer.chrome.com/docs/extensions/reference/api/sidePanel#event-onClosed 。

最终发布构建由既有流水线执行类型检查、单元/组件测试及真实扩展 E2E，使用 mock 模型，不读取用户密钥。预览已有 567 项测试、14 项浏览器测试通过；覆盖 Enter/按钮多模态发送、IME/换行/重复提交、截图遮盖、历史追问、清理、标签页切换、关闭重开、多窗口与 Worker 重启。

原生浏览器 X 的人工点击仍未自动化验证；现有自动化关闭覆盖快捷键和 API。Chrome 142/154 未分别运行完整回归，实际 CI Chromium 版本见测试日志。用户 Mac 固定加载目录不在 Linux 发布环境内，本次以商店包和 CI artifact 交付。

商店上传、提交审核与公开上线是三个独立状态，以各自返回结果报告，不将提交审核称为已公开。
