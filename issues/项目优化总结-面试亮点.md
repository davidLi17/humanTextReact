### 1. 手写 LRU 缓存 (最能展示基础功底)

**文件**: `entrypoints/shared/utils/LRUCache.ts`

**核心实现**:

```typescript
export class LRUCache<K, V> {
  private cache: Map<K, V>;
  private readonly maxSize: number;

  get(key: K): V | undefined {
    if (!this.cache.has(key)) return undefined;

    // 移到最近使用位置：先删除再添加
    const value = this.cache.get(key)!;
    this.cache.delete(key);
    this.cache.set(key, value);

    return value;
  }

  set(key: K, value: V): this {
    if (this.cache.has(key)) {
      this.cache.delete(key);
    } else if (this.cache.size >= this.maxSize) {
      // 删除最老的项（Map 的第一个元素）
      const oldestKey = this.cache.keys().next().value;
      this.cache.delete(oldestKey);
    }
    this.cache.set(key, value);
    return this;
  }
}
```

**面试要点**:

- **时间复杂度**: O(1) - 利用 Map 的特性
- **关键技巧**: Map 保持插入顺序，删除+添加实现 LRU
- **扩展功能**: TTL 过期机制、命中率统计

**可以深入讨论的问题**:

1. 为什么用 Map 而不是 Object？
2. 如何实现线程安全的 LRU？
3. 如何优化大量缓存时的内存占用？

### 2. 翻译缓存服务

**文件**: `entrypoints/background/translationCache.ts`

**业务价值**:

- 相同文本直接返回缓存，避免重复 API 调用
- 降低 API 成本，提升响应速度
- 缓存命中率统计，便于分析优化

**关键设计**:

```typescript
// 生成缓存 key - 使用 djb2 hash 算法
private simpleHash(str: string): string {
  let hash = 5381;
  for (let i = 0; i < str.length; i++) {
    hash = ((hash << 5) + hash) ^ str.charCodeAt(i);
  }
  return (hash >>> 0).toString(36);
}
```

### 3. 状态管理重构 (Zustand)

**文件**: `entrypoints/shared/store/`

**架构设计**:

```
store/
├── index.ts              # 统一导出
├── translationStore.ts   # 翻译状态
├── historyStore.ts       # 历史记录
└── settingsStore.ts      # 设置配置
```

**为什么选择 Zustand**:

1. **体积小**: 约 1.5KB gzip
2. **TypeScript 友好**: 完整类型推导
3. **无 Provider**: 不需要包裹组件
4. **与 React 18 兼容**: 支持并发模式

**面试要点**:

- 对比 Redux、MobX、Recoil 的优缺点
- 如何处理跨组件状态共享
- 状态持久化和同步策略

const { run: debouncedSearch } = useDebounceFn(
