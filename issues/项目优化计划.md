# 人话翻译器 - 项目优化计划

> 目标：提升项目技术亮点，适合大厂面试展示

## 优化方向

### Phase 1: 性能优化 ⚡

- 手写 LRU 缓存（面试亮点）
- 翻译结果缓存
- 输入防抖 (ahooks useDebounce)
- 搜索防抖

### Phase 2: 状态管理重构 🏗️

- 使用 wxt-zustand 跨 context 状态同步
- 统一 store 分层设计
- TypeScript 完整类型

### Phase 3: 设计系统 🎨

- Tailwind CSS v4
- Design Tokens
- 组件样式统一

## 技术栈

- zustand + wxt-zustand (状态管理)
- ahooks (防抖/节流)
- Tailwind CSS v4 (设计系统)
