## 问题发现和修复

### 🔍 通过日志发现的关键问题

从用户提供的日志中发现：

```
🔄 [TranslationService] 发送翻译更新
tabId: undefined  ❌ 问题所在！
```

**根本原因**：在 `TranslationService.translateText` 方法中：

- 正确计算了 `actualTabId = translationParams.tabId || tabId`
- 但在调用 `sendTranslationUpdate` 时错误地传递了原始的 `tabId` 参数
- 导致消息被错误路由到 popup 页面而不是 content script

### ✅ 修复内容

1. **修复 tabId 传递**：

   - 所有 `sendTranslationUpdate` 调用改为使用 `actualTabId`
   - 包括流式更新和最终完成信号
   - RequestManager.completeRequest 也使用 `actualTabId`

2. **增强调试日志**：
   - 添加翻译开始时的参数跟踪
   - 记录 tabId 的处理过程
   - 流式更新时的 tabId 信息

### 📊 触发方式区别

- **点击扩展图标**：在 popup 页面翻译（tabId 为空）✅ 正常
- **右键菜单/快捷键**：在当前页面 content 弹窗翻译（需要 tabId）✅ 已修复
